## 下载

| 系统 | 安装包 |
| --- | --- |
| Windows 10 / 11，x64 或 ARM64 | `GistManager-Setup-1.0.7-windows.exe` |
| macOS 12 及以上，Intel 或 Apple Silicon | `GistManager-1.0.7-macos.dmg` |

Windows 安装器自动选择系统原生架构；macOS 使用 Universal 应用，打开 DMG 后将应用拖入“应用程序”。macOS 包采用 ad-hoc 签名，首次打开可能需要在“系统设置 → 隐私与安全性”中允许。

ZIP 为各架构的便携包，`SHA256SUMS.txt` 提供下载文件的 SHA-256 校验值。已安装的客户端可通过“检查更新”安装本版本，程序会自动替换并重启；启用启动锁定时，重启后仍需解锁。
