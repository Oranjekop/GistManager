# Gist管理器 v1.0.1

修复界面文字重叠和系统设置弹窗留白问题，保持现有浅色与深色配色。

- Gist 卡片中的长标题、文件名和多行描述改为单行省略，避免覆盖相邻文字；悬停可查看完整标题和文件名。
- 卡片保留最小高度，并根据文字所需空间调整高度。
- 编辑区文件名、顶部账号名和底部状态消息过长时自动省略，避免挤压操作按钮。
- 系统设置弹窗左右留白统一为 20px，输入框与底部按钮右侧对齐。
- 增加长文本渲染回归检查，覆盖不同侧栏宽度、大小窗口和有无密码的设置页面。

## 下载

| 设备 | 安装包 |
| --- | --- |
| Windows x64 | `GistManager-Setup-1.0.1-windows-amd64.exe` |
| Windows ARM64 | `GistManager-Setup-1.0.1-windows-arm64.exe` |
| macOS Intel | `GistManager-1.0.1-darwin-amd64.dmg` |
| macOS Apple Silicon | `GistManager-1.0.1-darwin-arm64.dmg` |

macOS 打开 DMG 后，将应用拖入“应用程序”。安装包采用 ad-hoc 签名，首次打开可能需要在“系统设置 → 隐私与安全性”中允许。

ZIP 为便携应用包。`SHA256SUMS.txt` 提供所有下载文件的 SHA-256 校验值。
