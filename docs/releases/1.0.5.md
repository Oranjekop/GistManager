# Gist管理器 v1.0.5

修复 Windows 应用内更新成功后主窗口未显示、只出现 Windows Hello 验证框的问题。

- 更新完成后正常显示并重启主窗口，避免将后台更新进程的隐藏窗口设置传递给应用。
- 兼容旧版本更新器的隐藏启动方式，先显示应用窗口，再请求启动身份验证。
- 更新界面明确说明程序会自动替换并重启，无需安装向导；启用启动锁定时，提示重启后需要再次验证身份。
- 保留原有启动锁定和系统身份验证设置，检查更新本身不会请求 Windows Hello 或 Touch ID 验证。

## 下载

| 设备 | 安装包 |
| --- | --- |
| Windows x64 | `GistManager-Setup-1.0.5-windows-amd64.exe` |
| Windows ARM64 | `GistManager-Setup-1.0.5-windows-arm64.exe` |
| macOS Intel | `GistManager-1.0.5-darwin-amd64.dmg` |
| macOS Apple Silicon | `GistManager-1.0.5-darwin-arm64.dmg` |

macOS 打开 DMG 后，将应用拖入“应用程序”。安装包采用 ad-hoc 签名，首次打开可能需要在“系统设置 → 隐私与安全性”中允许。

ZIP 为便携应用包。`SHA256SUMS.txt` 提供所有下载文件的 SHA-256 校验值。已安装的客户端也可通过“检查更新”下载并安装本版本，程序会自动替换并重启；启用启动锁定时，重启后仍需解锁。
