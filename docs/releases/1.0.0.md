# Gist管理器 v1.0.0

原生 GitHub Gist 桌面客户端，支持 Windows 和 macOS。

- 三栏工作区，支持 Gist 搜索、创建、编辑及文件重命名和删除。
- 原生代码编辑器，提供语法高亮、查找替换、撤销重做和自动换行。
- 浅色与深色主题，配套应用图标。
- 系统凭据库保存 Token，支持软件密码、Windows Hello / PIN 和 Touch ID。
- 正式版与测试版更新检查，一键前往对应的 GitHub 下载页面。

## 下载

| 设备 | 安装包 |
| --- | --- |
| Windows x64 | `GistManager-Setup-1.0.0-windows-amd64.exe` |
| Windows ARM64 | `GistManager-Setup-1.0.0-windows-arm64.exe` |
| macOS Intel | `GistManager-1.0.0-darwin-amd64.dmg` |
| macOS Apple Silicon | `GistManager-1.0.0-darwin-arm64.dmg` |

macOS 打开 DMG 后，将应用拖入“应用程序”。当前 macOS 安装包采用 ad-hoc 签名，首次打开可能需要在“系统设置 → 隐私与安全性”中允许。

ZIP 为便携应用包。`SHA256SUMS.txt` 提供所有下载文件的 SHA-256 校验值。
