# Gist管理器 v1.0.2

增加应用内更新、程序密码清除与系统身份验证恢复，并改进 Windows Hello 的自动弹出和窗口关联。

- 支持在应用内检查、下载更新，完成 SHA-256 校验后重启安装；无需配置更新私钥。
- 安装前重新确认 GitHub 发布信息并校验文件；替换失败时恢复原版本，保留安装目录中的其他文件。
- 系统设置增加“清除程序密码”，验证当前密码后即可清除。
- 忘记密码时，可从锁定页或设置页通过 Windows Hello / PIN、Touch ID 验证后清除，无需输入原密码。
- 清除密码后关闭启动锁定和自动身份验证，保留 GitHub Token 和 Gist 数据；取消或验证失败不会修改密码。
- 启用系统身份验证后，每次启动或锁定自动请求一次验证；取消后仍可手动重试或使用软件密码。
- Windows Hello 使用主窗口作为所属窗口，替代独立 PowerShell 验证进程；解锁面板和密码恢复弹窗保持居中。
- 保持现有浅色与深色配色，并验证最小窗口尺寸下的设置、恢复和更新页面布局。

## 下载

| 设备 | 安装包 |
| --- | --- |
| Windows x64 | `GistManager-Setup-1.0.2-windows-amd64.exe` |
| Windows ARM64 | `GistManager-Setup-1.0.2-windows-arm64.exe` |
| macOS Intel | `GistManager-1.0.2-darwin-amd64.dmg` |
| macOS Apple Silicon | `GistManager-1.0.2-darwin-arm64.dmg` |

macOS 打开 DMG 后，将应用拖入“应用程序”。安装包采用 ad-hoc 签名，首次打开可能需要在“系统设置 → 隐私与安全性”中允许。

ZIP 为便携应用包。`SHA256SUMS.txt` 提供所有下载文件的 SHA-256 校验值。
