# Gist管理器 v1.0.3

优化整体界面和密码管理体验，修复左侧 Gist 卡片悬停时背景与圆角边缘不一致的问题。

- 保持原有浅色、深色配色，统一三栏间距、卡片圆角、文件选中状态及底部操作栏。
- 修复 Gist 卡片悬停背景覆盖不完整、圆角外露出背景的问题，保留键盘上下选择和长文本提示。
- 系统设置将程序密码与启动锁定分开管理，提供独立的设置、修改和清除密码操作。
- 首次设置程序密码后开启启动锁定；修改密码保留已有锁定设置，关闭启动锁定保留程序密码。
- 清除密码时可选择验证当前密码或使用 Windows Hello / PIN、Touch ID；忘记密码时无需原密码，也无需预先开启自动身份验证。
- 清除密码后关闭启动锁定和自动身份验证，保留 GitHub Token 与 Gist 数据；取消或验证失败不会修改密码。
- 取消密码操作会返回设置并保留未保存的选项；验证过程中防止重复提交，成功后显示明确结果。
- 系统身份验证暂时不可用时，仍可使用当前程序密码修改密码并保留已有验证设置。
- 优化锁定页、搜索无结果提示及设置表单，适配最小窗口尺寸和深浅色主题。

## 下载

| 设备 | 安装包 |
| --- | --- |
| Windows x64 | `GistManager-Setup-1.0.3-windows-amd64.exe` |
| Windows ARM64 | `GistManager-Setup-1.0.3-windows-arm64.exe` |
| macOS Intel | `GistManager-1.0.3-darwin-amd64.dmg` |
| macOS Apple Silicon | `GistManager-1.0.3-darwin-arm64.dmg` |

macOS 打开 DMG 后，将应用拖入“应用程序”。安装包采用 ad-hoc 签名，首次打开可能需要在“系统设置 → 隐私与安全性”中允许。

ZIP 为便携应用包。`SHA256SUMS.txt` 提供所有下载文件的 SHA-256 校验值。已安装的客户端也可通过“检查更新”下载并安装本版本。
