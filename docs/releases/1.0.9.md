# GistManager v1.0.9

修复新版 macOS 在访达中给 GistManager 图标套上浅灰色外框、导致蓝色图标缩小的问题。新版安装包使用 macOS 原生分层图标，保留蓝色底板和双代码卡片。

| 系统 | 安装包 |
| --- | --- |
| macOS 12 及以上，Intel 或 Apple Silicon | `GistManager-1.0.9-macos.dmg` |
| Windows 10 / 11，x64 或 ARM64 | `GistManager-Setup-1.0.9-windows.exe` |

使用旧中文名称应用包的 macOS 用户，请退出应用后用 DMG 安装。ZIP 为各架构的便携包，可用 `SHA256SUMS.txt` 校验。
