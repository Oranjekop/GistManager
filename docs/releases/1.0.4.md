# Gist管理器 v1.0.4

改善代码编辑器滚动条的可见度，提供简体中文 Windows 安装器，并统一使用正式版本更新与发布。

- 提高代码区域横向、纵向滚动条的对比度，在浅色和深色主题下均清晰可见，保留悬停反馈和拖动操作。
- Windows 安装器改为简体中文，包含安装目录、安装进度、完成页、桌面快捷方式选项和卸载界面。
- 移除测试版更新通道，只检查最新正式版本；旧通道设置不再影响更新。
- 更新检查及安装验证拒绝草稿、预发布和带测试后缀的版本。
- 移除测试版构建与滚动发布逻辑。推送主分支或创建 Pull Request 运行检查，只有与配置版本一致的正式标签才编译和发布安装包。

## 下载

| 设备 | 安装包 |
| --- | --- |
| Windows x64 | `GistManager-Setup-1.0.4-windows-amd64.exe` |
| Windows ARM64 | `GistManager-Setup-1.0.4-windows-arm64.exe` |
| macOS Intel | `GistManager-1.0.4-darwin-amd64.dmg` |
| macOS Apple Silicon | `GistManager-1.0.4-darwin-arm64.dmg` |

macOS 打开 DMG 后，将应用拖入“应用程序”。安装包采用 ad-hoc 签名，首次打开可能需要在“系统设置 → 隐私与安全性”中允许。

ZIP 为便携应用包。`SHA256SUMS.txt` 提供所有下载文件的 SHA-256 校验值。已安装的客户端也可通过“检查更新”下载并安装本版本。
