# GistManager v1.0.8

应用名称统一为 GistManager，沿用现有蓝色配色和中英文界面。

- 统一窗口、侧栏、系统应用菜单、身份验证提示、安装器和快捷方式中的名称。
- Windows 可执行文件使用 `GistManager.exe`，macOS 应用包使用 `GistManager.app`。
- 已有安装继续使用原配置目录和凭据，保留账号、密码、语言和布局设置；新安装使用 `GistManager` 配置目录。
- Windows 安装器沿用已登记的安装位置，清理旧名称的程序和快捷方式，创建新的 GistManager 入口。
- 同步更新 README、项目封面和自动构建中的应用路径。

## 升级说明

Windows 可通过应用内“检查更新”升级。若需要将原中文程序文件名及快捷方式一并改名，请退出应用后运行安装器覆盖安装。

**macOS 旧版首次升级本版本请使用 DMG 安装。** 旧版更新器固定使用中文应用包名，无法安装改名后的更新包。退出旧应用，将 `GistManager.app` 拖入“应用程序”，确认新应用正常后移除旧中文应用。账号和设置会自动沿用。

## 下载

| 系统 | 安装包 |
| --- | --- |
| Windows 10 / 11，x64 或 ARM64 | `GistManager-Setup-1.0.8-windows.exe` |
| macOS 12 及以上，Intel 或 Apple Silicon | `GistManager-1.0.8-macos.dmg` |

Windows 安装器自动选择系统原生架构；macOS 使用 Universal 应用。macOS 包采用 ad-hoc 签名，首次打开可能需要在“系统设置 → 隐私与安全性”中允许。

ZIP 为各架构的便携包，`SHA256SUMS.txt` 提供下载文件的 SHA-256 校验值。应用更新后会重启，启用启动锁定时仍需解锁。
