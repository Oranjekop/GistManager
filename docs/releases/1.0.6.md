# Gist管理器 v1.0.6

升级 MyGo v0.7.0，并将 Windows 和 macOS 的安装包分别合并为一个文件，无需手动区分处理器架构。

- Windows 简体中文安装器同时包含 x64 和 ARM64 程序，安装时自动选择系统原生架构。
- macOS Universal 应用和 DMG 同时支持 Intel 与 Apple Silicon。
- 应用内更新保留四种架构的便携 ZIP，只下载适合当前设备的程序。
- 构建工具链升级至 Go 1.27.3，保留现有浅色、深色配色及密码与启动锁定设置。
- 保留更新重启后的窗口显示修复，兼容旧版本更新器的隐藏启动方式。

## 下载

| 系统 | 安装包 |
| --- | --- |
| Windows 10 / 11，x64 或 ARM64 | `GistManager-Setup-1.0.6-windows.exe` |
| macOS 12 及以上，Intel 或 Apple Silicon | `GistManager-1.0.6-macos.dmg` |

Windows 运行安装器；macOS 打开 DMG 后，将应用拖入“应用程序”。macOS 包采用 ad-hoc 签名，首次打开可能需要在“系统设置 → 隐私与安全性”中允许。

ZIP 为各架构的便携应用包，`SHA256SUMS.txt` 提供所有下载文件的 SHA-256 校验值。已安装的客户端可通过“检查更新”下载并安装本版本，程序会自动替换并重启；启用启动锁定时，重启后仍需解锁。
